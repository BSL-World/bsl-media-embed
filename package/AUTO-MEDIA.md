# Local media — candidate 0.4.1

This replaces the mandatory JSON map workflow from 0.4.0. Install the package over the existing package without uninstalling children. Choose a DEDICATED public media folder in Components → BSL Media → Options. On the local Windows server this may be D:/BSL-Media-Test-Files. On hosting, /home/account/media is an example absolute path; ../media means a sibling of the Joomla site root. Relative paths ALWAYS resolve against JPATH_ROOT, not the current script's working directory. PHP must have read/traverse permission and open_basedir must permit access. The component creates no media folders or OS permissions.

MP3, MP4 and Ogg Opus (.opus) files directly inside that folder are automatically discovered. No JSON editing, registration or reindex button is needed. New/deleted files are noticed on the next request. No recursive scanning: neighbouring folders, subfolders, dotfiles, unsupported extensions and filenames containing forbidden separators/control characters/percent/colon/dot-dot are excluded. This is intentionally a folder of PUBLIC media: every eligible direct file is public, independent of article ACL. Never select a mixed private directory.

The component page shows a table of keys and files, refreshed when opened. For sample.mp3 the keys sample.mp3 and (if unique) sample work. For song.mp3 + song.opus, use full filenames: the ambiguous song key returns 409. Names with spaces/Unicode receive a deterministic media-HASH key shown in the table; there is no need to rename such files. These opaque identifiers are NOT passwords or authorization. Saved 0.4.0 aliases are still read first and retained in a hidden form field so existing articles can continue using them. They are not a required part of new setup.

Use {bslaudio file="song.opus"}, {bslaudio file="song.mp3"}, {bslvideo file="clip.mp4"} or a generated key from the table. Existing shortcode syntax/player markup stays unchanged. For Unicode/space names copy the generated key. URLs use index.php?option=com_bslmedia&task=media.stream&file=KEY. Add &download=1 for attachment download.

Only MP3, MP4 and Opus are delivered, including uppercase suffixes. MIME: audio/mpeg, video/mp4, audio/ogg; codecs=opus. MIME follows the suffix; admins must provide genuine media. nosniff is set. Document/distribution delivery remains BSL Download Service's responsibility. Attachment names use RFC 5987 encoding with an ASCII fallback to avoid header injection.

GET/HEAD and one byte range are supported. HEAD ignores Range and returns full metadata without body. Invalid/multipart/overflowing/unsatisfiable ranges return 416 with Content-Range bytes */SIZE. Successful ranges return 206 and exact Content-Length/Content-Range; Accept-Ranges bytes. Other methods return 405; invalid keys 400; missing/unsupported files 404; forbidden paths 403; ambiguous keys 409; unavailable/unconfigured root 503. Streaming uses bounded 64 KiB reads. 64-bit PHP required; Cache-Control no-store, no ETag/If-Range caching. Web/proxy compression must not change lengths.

Canonical paths, containment, post-open realpath and descriptor metadata checks remain. Escaping symlinks/junctions must not expose outside files; in-root links are allowed. Root/parents must be writable only by trusted administrators: portable PHP cannot guarantee race-free access against a hostile concurrent filesystem writer. Do not replace files during delivery. The catalog is scanned on each automatic lookup (O(number of direct entries)); no database row per file is created and throughput for very large directories has not been benchmarked.

Package versions are coordinated. Component params/plugin IDs, enabled/access/ordering must survive upgrade and repeated upgrade; verify on both real Joomla 5/6. Uninstall removes extension code, never administrator-owned media, and is not rollback. Restore files/DB/settings from backup to roll back. No publication before acceptance.

Production migration remains a separately authorized task: inventory all download.php consumers (media, documents, feeds/distributions/external links), back up files/DB/settings, install accepted package, configure dedicated root and verify every legacy key. Existing names may need saved aliases if they differ from filenames. Verify new links, GET/HEAD/206/416, download and actual audible start/seek/pause/resume on desktop/mobile, JCE/TinyMCE/Manager, Yandex/YouTube and cache. Keep old download.php until every consumer is accounted for; delete only after separate approval. Documents/distributions stay with BSL Download Service. Restore backup rather than uninstalling the package for rollback.

Still required: real Joomla update/settings preservation, web PHP/HTTP/permissions/open_basedir, symlink/junction tests on host, large-file delivery, sound/seek/download confirmed by Alexander and Joomla 5 acceptance. Fixture Opus bytes used in local tests are not playback evidence.
