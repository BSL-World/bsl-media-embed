# BSL Media Embed

Candidate 0.5.2 uses com_bslmedia: MB/GB limits, two media subfolder levels, one web folder dialog, immediate multi-file upload and copying shortcodes. Folder filtering and reversible name/size/file-modification-time sorting change only the table, not upload destination. No deletion, renaming, moving or overwriting. Existing aliases/keys, shortcode syntax and provider behaviour remain. See package/LIBRARY.md.

BSL Media Embed is a content plugin for Joomla that replaces editor-safe shortcodes with responsive HTML5 audio and video players.

The plugin is intended for media files delivered through a controlled `download.php` gateway. Only a logical file key is stored in the article, so visual editors such as JCE and TinyMCE do not need to preserve the final media-player markup.

## Features

- Editor-safe `{bslvideo ...}` and `{bslaudio ...}` shortcodes.
- Responsive HTML5 video and audio players.
- Optional video width and height.
- Optional maximum audio-player width.
- Strict validation of logical file keys.
- English and Russian localization.
- Joomla 5 and Joomla 6 support.
- Joomla Update System integration.
- Yandex Music and YouTube shortcodes, generated by the BSL Media editor button in the package.

## External players (0.3.0 development candidate)

Click **BSL Media** in the editor's extra buttons or JCE's Joomla menu. Paste a share link or a single official iframe and insert the generated shortcode. No original HTML or external metadata is stored.

```text
{bslyandexmusic album="3513" track="42612"}
{bslyoutube video="ZyBl3noTNSs"}
```

Yandex uses 100% width and 122px height; YouTube uses an adaptive 16:9 frame. Playback starts manually. Only these providers are allowed. Provider availability, account/region restrictions and site CSP can affect playback.

For installation over 0.2.0, use the complete package ZIP without uninstalling this content plugin. The button is a separate editors-xtd plugin. Package updates use a separate feed; the old standalone feed is retained for legacy installations. Real Joomla/JCE installation and playback acceptance are still required before deployment.

## Requirements

- Joomla 5.x or Joomla 6.x.
- PHP 8.1 or later.
- A configured `/download.php` gateway on the Joomla site.
- Media files mapped to logical keys by the gateway.

## Usage

Video:

```text
{bslvideo file="short-video-01"}
```

Video with custom initial dimensions:

```text
{bslvideo file="short-video-01" width="640" height="360"}
```

Audio:

```text
{bslaudio file="manifest-audio"}
```

Audio with a custom maximum width:

```text
{bslaudio file="manifest-audio" width="480"}
```

The `file` value is a logical key, not a filesystem path or public media URL. Media is requested through:

```text
/download.php?file=manifest-audio&source=site
```

## Security model

The plugin does not accept arbitrary filesystem paths. File access remains under the control of BSL Download Service and its external registries.
